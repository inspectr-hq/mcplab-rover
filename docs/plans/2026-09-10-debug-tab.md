# Rover Debug Tab Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a live Debug tab that explains endpoint connectivity, active-page matching, provider element presence, and Rover state.

**Architecture:** Provider adapters expose semantic debug checks. The background service worker gathers endpoint, active-tab, provider, and persisted-session data into one snapshot. The popup renders that snapshot and polls only while Debug is selected.

**Tech Stack:** TypeScript, Chrome extension messaging and tabs APIs, Vitest, Vite.
